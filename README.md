# Portfolio Minh Nhàn

Trang portfolio cá nhân: giới thiệu, dự án tại UEL và hoạt động sự kiện.

- Trang tĩnh, chỉ gồm `index.html` và thư mục `images/`, không cần build.
- Deploy trên Vercel: Import repo → Framework Preset: **Other** → để trống Build Command và Output Directory → Deploy.
- Sửa nội dung: mở `index.html`, tìm đoạn `SỬA NỘI DUNG CỦA BẠN Ở ĐÂY`.
